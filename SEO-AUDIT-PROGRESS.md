# SEO AUDIT PROGRESS — AFB Taxis

> Generated by SEO Prompt Master · Phases 2–4. Living record. Baseline 2026-08-31 against live `https://www.afbtaxis.com` + source `main@5ba0865`.

## Stack Report

- **Framework:** Vite 5.4 + React 18.3 + TypeScript + React Router 7 + `react-helmet-async`. Tailwind 3.
- **Rendering:** CSR SPA (`createRoot`, not `hydrateRoot`). Build: `generate-sitemap.js` → `vite build` → `prerender-seo.js` writes per-URL `dist/**/index.html` with swapped title/canonical and a **hidden** (`opacity:0;width:1px`) text+link dump. Googlebot can JS-render; most AI crawlers will not (`docs/05`, `docs/10`).
- **Routing:** `src/App.tsx` file/config routes under `PublicLayout`. Home is eager; blog, trajets, partenaires, SEO landings are `React.lazy`.
- **Multilingual:** FR/EN/AR/ES client toggle only. No locale URLs / hreflang (`docs/02`). Score i18n 10 pts redistributed into Metadata.
- **SEO infra already present:** `index.html` TaxiService + WebSite + SiteNavigationElement + BreadcrumbList JSON-LD; `public/robots.txt`; `public/sitemap.xml` (regenerated at build); `public/llms.txt` (not a GEO lever, `docs/10`); prerender for home, `/blog`, 32 posts, 4 trajets, `/partenaires`.
- **Verify commands:** `npm run typecheck` · `npm run lint` · `npm run build`.
- **Verticals:** V03 Local Service (TaxiService/LocalBusiness, NAP, `sameAs`) + V13 Blog (`Article`, internal linking).
- **Live tool (Phase 0):** `node .seo-prompt-master/tools/seo-audit.mjs --url https://www.afbtaxis.com --max 40` → **92/100, P1 0, P2 0, P3 95** on the **34 sitemap URLs**. The tool never fetched trajets, partenaires, or SEO landings (not in sitemap). Source review still finds P1/P2 the crawler sample missed.

### Deliberate skips (with reason)
- ⏭️ **hreflang / locale URLs** — the i18n toggle has no localized content URLs. Inventing `/en/` or `?lang=` without translated unique content would create duplicates (`docs/02`, `docs/13`). Redistributed i18n points into metadata.
- ⏭️ **Migrate Vite → Next.js SSR** — recommended in `SEO_Improvement_Plan.md` but is a stack rewrite, not this pass. Prerender is the in-stack fix (`docs/05`).
- ⏭️ **Legal pages as standalone URLs** — content lives in a modal; splitting it is a product call, not an indexing blocker.
- ⏭️ **`llms.txt` removal** — harmless; `docs/10` says not to *recommend* it as a fix, not that owning one is a P1.
- ⏭️ **Title length ~60 chars on every blog post** — practical snippet target only (`docs/01`); no ranking rule. Leave article titles intact.
- ⏭️ **FAQPage rich-result CTR** — markup reflects visible FAQ; rich result is restricted since 2023 (`docs/08`). Keep markup, don't promise stars.
- ⏭️ **AggregateRating** — on-page reviews in `Reviews.tsx` are static copy (commit history: MOCKED). Do **not** add `AggregateRating` (`docs/08`, V03).
