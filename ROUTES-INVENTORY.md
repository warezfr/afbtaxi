# ROUTES INVENTORY — AFB Taxis

> Generated by SEO Prompt Master · Phase 1. Updated 2026-08-31 against `main` @ `5ba0865` and live `https://www.afbtaxis.com`.

**Stack:** Vite 5 + React 18 + TypeScript + React Router 7 (CSR SPA) with a post-build HTML prerender (`scripts/prerender-seo.js`) and sitemap generator. Deployed on Vercel (`cleanUrls`, no trailing slash).
**Multilingual:** UI toggle FR/EN/AR/ES in `src/lib/i18n.tsx` — **no locale URLs, no hreflang**. Language is client-state only (`docs/02`: do not mint `?lang=` URLs). Default visible content is French.
**Matched verticals:** V03 Local Service Business (primary) + V13 Blog overlay. Travel (V09) only as airport-transfer adjacent — not a hotel/tour platform.

**Canonical host:** `https://www.afbtaxis.com` (non-www and http 308 → www). `COMPANY.website` in source still said `https://www.afbtaxis.fr` (NAP mismatch, `docs/08` / V03).
