# AFB Taxis

Site web professionnel pour AFB Taxis — service de taxi à Fontainebleau et en Île-de-France.

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Déploiement Vercel

1. Connectez votre dépôt GitHub/GitLab à Vercel
2. Framework Preset : **Vite**
3. Build Command : `npm run build`
4. Output Directory : `dist`
5. Ajoutez vos variables d'environnement (VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY)
